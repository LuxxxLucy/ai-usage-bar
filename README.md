# usage bar

A SwiftBar Plugins that shows the subscription and credit usages in the MacOS menu bar.

See `claude-pulse.1m.sh`

The plugin displays, in order, OpenRouter credit, DeepSeek balance, Claude usage, Codex usage. A red dot in the begininng showing whether Claude or Codex is active.
